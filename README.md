# Tensor Puzzles

My work through [Tensor Puzzles](https://github.com/srush/Tensor-Puzzles) by Sasha Rush (with Marcos Treviso), done as PyTorch review.

Each puzzle reimplements a standard tensor function in one line using only broadcasting, arithmetic, comparison, `@`, indexing and earlier puzzle functions.

Open `Tensor_Puzzlers.ipynb` in Colab or Jupyter to run it.
